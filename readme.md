# Bengaluru House Price Prediction

## 🚀 Overview
This project predicts house prices in Bengaluru, India using machine learning models. The goal is to provide a tool that helps buyers, sellers, and real estate professionals estimate property prices based on key features.

**Key Features:**
- Predicts property prices based on location, bedrooms, bathrooms, and other features
- Uses regression models: Linear Regression
- Handles missing data and categorical features
- Provides insights on influential factors affecting prices
- Includes exploratory data analysis (EDA) and visualization

---

## 🛠 Technology Stack
- **Programming Language:** Python 3.x
- **Libraries / Frameworks:**  
  - Pandas, NumPy  
  - Matplotlib, Seaborn  
  - Scikit-learn  
- **IDE / Environment:** Jupyter Notebook / VS Code

---

## 📂 Dataset
- Dataset collected from Bengaluru real estate listings  
- Features may include:
  - Location
  - Total Square Feet
  - Number of Bedrooms
  - Number of Bathrooms
  - Type of property (Apartment / Villa / House)  
- Target: **Price in INR**

**Note:** Data cleaning is performed to handle null values, standardize units, and remove outliers.

---

## 🧠 Model Architecture
- Preprocessing:
  - Handling missing values  
  - Encoding categorical variables (Location)  
  - Feature scaling (if required)  
- Machine Learning Models:
  - Linear Regression
- Evaluation Metrics:
  - MSE (Mean Squared Error)
  - R² Score
